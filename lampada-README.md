## Description ✨

This project, named "lampada" (Portuguese for "light bulb"), is a minimalist web application designed to demonstrate the interaction between HTML, CSS, and JavaScript. It features a visual representation of a light bulb that can be toggled between "on" and "off" states via a button click. The status of the bulb and the button's text dynamically update to reflect the current state.

## Features 🌟

- **Interactive Light Bulb:** Click a button to toggle the light bulb's state between on and off.

## Usage & How to Use 🚀

This project is a straightforward demonstration of front-end web development.

1.  **Open the Application:** Navigate to the `lampada.html` file in your web browser.
2.  **Interact:**
    *   You will see a light bulb emoji (💡) and a button labeled "Ligar" (Turn On).
    *   Click the "Ligar" button.
    *   The light bulb will change its appearance, and the status text will update to "A lâmpada está acesa" (The light bulb is on). The button text will change to "Desligar" (Turn Off).
    *   Click the "Desligar" button.
    *   The light bulb will revert to its off state, the status text will update to "A lâmpada está apagada" (The light bulb is off), and the button text will change back to "Ligar" (Turn On).

This project is ideal for learning the basics of DOM manipulation, event handling, and CSS class toggling in JavaScript.

## Project Structure 🏗️

The project follows a simple and organized structure:

```
lampada/
├── css/
│   └── lampada.css
├── js/
│   └── lampada.js
└── lampada.html
```

- **`lampada.html`:** The main HTML file that structures the page, includes the light bulb, status display, and button, and links to the CSS and JavaScript files.
- **`css/lampada.css`:** Contains the styling rules for the application, including styles for the body, the light bulb emoji, the status text, and the button, as well as the `.apagada` class for the off state.
- **`js/lampada.js`:** Implements the core interactive logic. It handles button clicks, toggles the `.apagada` CSS class on the light bulb, and updates the status text and button label accordingly.
