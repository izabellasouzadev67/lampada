## Description ✨

Este projeto, chamado "lampada", é uma aplicação web minimalista criada para demonstrar a interação entre HTML, CSS e JavaScript. Ele apresenta uma representação visual de uma lâmpada que pode alternar entre os estados "ligada" e "desligada" por meio de um clique em um botão. O status da lâmpada e o texto do botão são atualizados dinamicamente para refletir o estado atual.

## Features 🌟

- Lâmpada Interativa:** Clique em um botão para alternar o estado da lâmpada entre ligada e desligada.
- **Atualizações Dinâmicas de Status:** A aplicação exibe o status atual da lâmpada (Ligada/Desligada).
- **Feedback Visual:** O emoji de lâmpada (💡) altera sua aparência (escala de cinza e opacidade) para representar visualmente seu estado.
- **Design Responsivo:** Estilização básica que garante a usabilidade da aplicação em diferentes tamanhos de tela (embora não tenha sido extensivamente testada).
- **Manipulação Simples do DOM:** Demonstra conceitos fundamentais de JavaScript, como *event listeners* (ouvintes de eventos) e manipulação de elementos do DOM.

## Tech Stack 💻

-- **HTML:** Para estruturar o conteúdo da página web.
- **CSS:** Para definir o estilo da aparência da lâmpada, do texto de status e do botão.
- **JavaScript:** Para implementar a funcionalidade interativa e a manipulação do DOM.

## Como usar 🚀

Este projeto é uma demonstração simples de desenvolvimento web front-end.

1.  **Abra a aplicação:** Abra o arquivo `lampada.html` no seu navegador.
2.  **Interaja:**
*   Você verá um emoji de lâmpada (💡) e um botão com o rótulo "Ligar". 
*   Clique no botão "Ligar". 
*   A aparência da lâmpada mudará, e o texto de status será atualizado para "A lâmpada está acesa". O texto do botão mudará para "Desligar". 
*   Clique no botão "Desligar". 
*   A lâmpada voltará ao estado desligado, o texto de status será atualizado para "A lâmpada está apagada" e o texto do botão voltará a ser "Ligar".

Este projeto é ideal para aprender os fundamentos da manipulação do DOM, tratamento de eventos e alternância de classes CSS usando JavaScript.

## Project Structure 🏗️

The project follows a simple and organized structure:

```
lampada/
├── css/
│   └── lampada.css
├── js/
│   └── lampada.js
└── lampada.html
```

-**`lampada.html`:** O arquivo HTML principal que estrutura a página; inclui a lâmpada, a exibição de status e o botão, além de realizar a vinculação com os arquivos CSS e JavaScript.
- **`css/lampada.css`:** Contém as regras de estilo da aplicação, incluindo definições para o corpo da página, o emoji de lâmpada, o texto de status e o botão, bem como a classe `.apagada` para representar o estado desligado.
- **`js/lampada.js`:** Implementa a lógica interativa principal. Gerencia os cliques no botão, alterna a classe CSS `.apagada` na lâmpada e atualiza o texto de status e o rótulo do botão conforme necessário.
